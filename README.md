# TypeScript Assignment 1

## Overview

This repository contains my TypeScript assignment. The main goal of this assignment is to practice TypeScript fundamentals, including functions, union types, type narrowing, generics, interfaces, classes, inheritance, and asynchronous programming.

## Assignment Topics

- Functions with default parameters
- Union types and type narrowing
- Readonly tuples
- Generic functions
- Interfaces and array methods
- Generic constraints and keyof
- Classes, inheritance, and access modifiers
- Promises and asynchronous functions
